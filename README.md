## 2026-10-01 - Starting a blog via git README.md

This is just an experiment. Why not blogging just by filling out the readme of a Git repository?
Because there are different places that renders already on the internet, so why not?

A long, long time ago, I used to have a blog on the internet.
I closed it down a very long time ago because it was all too much effort for me.

Now I’ve had the idea: why not just create a little blog in a README.md of a Git repository?

Since GitHub suspended my account (see below) i'm just been using several different git project services to avoid that happening again.

I have just the idea and started with a nearly empty README here:
I looked around but didn't found other people doing this.

So here it is:
